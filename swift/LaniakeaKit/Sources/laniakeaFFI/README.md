`include/laniakeaFFI.h` is generated by UniFFI (`scripts/package-xcframework.sh` copies it from the
output of `scripts/gen-swift-bindings.sh`); do not edit it. `scripts/check-bindings.sh` compares it with
a fresh generation.

This C target owns the header of the Rust static library. The XCFramework deliberately contains no
headers or module maps: Xcode copies every XCFramework's headers into one shared `include/` directory,
so two packages that each ship a `module.modulemap` collide ("Multiple commands produce
include/module.modulemap"). SwiftPM derives this target's module map from the header
(`module laniakeaFFI { umbrella header "laniakeaFFI.h" }`).

`laniakeaFFI.c` is an intentionally empty translation unit; see its comment.
